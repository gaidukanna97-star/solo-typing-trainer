# Соло — тренажер сенсорного набору

Браузерний тренажер, який послідовно навчає сенсорного набору українською (ЙЦУКЕН) та англійською (QWERTY): від постановки рук на домашньому ряду до зв'язного тексту. Робота для хакатону [Typing Race 2026](https://stszu.github.io/Typing-Race-2026-Hackathon/).

Це не тест швидкості. Програма формує моторну навичку: одна клавіша — один палець, точність перед швидкістю, нова складність лише після закріплення попередньої.

- **Демо:** https://solo-typing-trainer.vercel.app/ (дзеркало: https://gaidukanna97-star.github.io/solo-typing-trainer/)
- **Репозиторій:** https://github.com/gaidukanna97-star/solo-typing-trainer

## Запуск

Статичний сайт без збирання. Для локального запуску й тестів потрібен лише Node.js 20+; `npm install` не обов'язковий — єдина залежність (`@vercel/blob`) потрібна тільки серверній функції на Vercel.

```bash
npm start          # http://localhost:8080 — сайт і локальний сервер кабінетів (дані в .local-data/)
```

Будь-який інший статичний сервер теж підходить (GitHub Pages, `python -m http.server`): тоді тренажер звертається до основного сервера кабінетів, а якщо той недоступний — працює з локальним кабінетом. Відкривати `index.html` напряму з диска не можна: браузер не завантажує ES-модулі з `file://`.

```bash
npm test           # 95 автоматичних перевірок ядра, програми, словників, кабінетів, сервера й сертифікатів
npm run test:e2e   # наскрізна перевірка в Edge/Chrome (сценарій демонстрації журі)
npm run build:data # перебудувати data/derived/ із сировини
npm run build:outline  # перебудувати план програми data/curriculum/outline-*.json
```

Для локального запуску змінні середовища не потрібні. Серверній функції на Vercel потрібні дві — їх перелічено в [.env.example](.env.example); самих секретів у репозиторії немає.

## Навчальна модель

Докладно — у [docs/pedagogy.md](docs/pedagogy.md).

| Етап | Що робить учень | Вправ (uk / en) |
|---|---|---|
| 1. Клавіатурні гами | Нові клавіші по дві, послідовні й дзеркальні рухи, чергування рук, вертикальні переходи, один палець на кількох клавішах, Shift, цифри, знаки, ритм під метроном | 26 / 25 |
| 2. Слова з відкритих клавіш | Реальні частотні слова, у яких немає жодного ще не вивченого символу; подвоєння, рух одним пальцем між рядами, чергування рук, апостроф, дефіс, великі літери, `ґ є ї і` | 19 / 18 |
| 3. Академія | 10 модулів: біграми, триграми, морфеми, переходи одним пальцем, чергування й перекати, подвоєння, знаки й числа, спринти, речення, абзаци | 25 / 25 |

Гами та слова чергуються: щойно відкрито дві нові клавіші, їх одразу закріплюють словами. Кожна вправа має дві фази:

- **Розучування** — екранна клавіатура з кольорами пальців і підказкою наступної клавіші. Результат не зараховується.
- **Залік** — клавіатуру й підказку приховано, на екрані лише текст. Вправа закріплена після трьох успішних заліків поспіль.

Після кожної залікової спроби програма показує SPM, точність, помилки, час, помилки за символами, найповільніші переходи, нерівномірність ритму, порівняння з особистим рекордом і **одну конкретну наступну дію**.

## Особистий кабінет і гейміфікація

- **Кабінет без пошти й телефону.** Потрібні ім'я, пароль і секретне питання з відповіддю.
- **Вхід з будь-якого комп'ютера.** Кабінет зберігається на сервері (функція Vercel + приватне сховище Vercel Blob, безкоштовний тариф). У браузері лежить копія, тому тренажер працює й без мережі, а прогрес відправляється, щойно з'явиться зв'язок. Якщо прогрес змінено на іншому пристрої, береться серверна копія.
- **Відновлення пароля** — за секретним питанням: ім'я → питання → відповідь → новий пароль. Після п'яти невдалих спроб — пауза на 10 хвилин. Питання й пароль можна змінити в кабінеті.
- **Що зберігає сервер:** ім'я, хеш пароля, секретне питання, хеш відповіді (scrypt із сіллю) і прогрес. Жодної пошти, телефону чи аналітики; набрані тексти на сервер не надсилаються. Кабінет разом з усіма даними видаляється із сервера кнопкою в кабінеті.
- **Навчання не залежить від сервера.** Якщо він недоступний, можна створити локальний кабінет у браузері (з тим самим секретним питанням); усі вправи працюють офлайн.
- **Досвід (XP)** дає тільки зарахована спроба: 10 XP за залік, +5 за точність від 99%, +10 за спробу без жодної помилки, 40 за закріплену вправу, 100 за модуль Академії, 30 за повне заняття дня. Швидкість без точності не винагороджується.
- **Звання:** Новачок → Учень → Практик → Знавець → Профі → Майстер → Віртуоз.
- **Досягнення:** 15 відзнак — за перший залік, домашній ряд, усю абетку, етапи, Академію, темп 150/225/300 SPM на словах і текстах, серії днів, обидві розкладки.
- **Зріз швидкості й сертифікати.** Зв'язний текст на 450+ символів без підказок. Обидві умови обов'язкові одночасно: бронзовий — від 150 SPM і 96%, срібний — від 200 SPM і 97%, золотий — від 250 SPM і 98%. Сертифікат з іменем, результатом і датою можна надрукувати або зберегти як PDF. Він формується в браузері й серверної перевірки справжності не має; темп понад 1200 SPM вважається автоматичним введенням. Пороги — у `src/core/config.js`.
- Звання, досягнення й сертифікати особисті. **Рейтингу між користувачами немає.**

## Архітектура

```text
index.html, styles.css, sw.js     оболонка, стилі, офлайн-кеш
src/core/                         ядро без DOM — покрите тестами
  layouts.js                      клавіші, пальці, розкладки, нормалізація
  session.js                      рушій спроби: натискання, помилки, SPM, точність, ритм
  curriculum.js                   програма трьох етапів і генерація вправ
  analysis.js, feedback.js        слабкі клавіші, повільні переходи, наступна дія
  storage.js                      прогрес у localStorage, експорт та імпорт
  accounts.js                     копія серверного кабінету в браузері та локальні кабінети
  remote.js                       клієнт сервера кабінетів
  gamification.js                 досвід, звання, досягнення, серії днів
  certificate.js                  зріз швидкості та сертифікати
  customtext.js                   перевірка власного тексту (.txt / .md)
  config.js                       пороги рівнів і правила зарахування
src/ui/                           сторінки, тренувальний екран, екранна клавіатура
src/data/                         відтворювана обробка словників (Hunspell, частоти, n-грами)
server/account-service.js         серверна логіка кабінетів (без залежностей, покрита тестами)
api/account.js                    функція Vercel: POST /api/account + сховище Vercel Blob
scripts/                          збирання даних, локальний сервер, наскрізна перевірка
dictionaries/                     незмінна сировина + manifest.json із SHA-256
data/derived/                     очищені списки слів і таблиці n-грам
data/curriculum/                  тексти Академії та згенерований план програми
data/filters/                     блок-листи
tests/                            автоматичні перевірки
```

Навчальна частина працює повністю в браузері; сервер потрібен лише для кабінетів. Розкладка визначається за набраним символом, а не за фізичним кодом клавіші, тому тренажер працює з будь-яким варіантом української розкладки (зокрема там, де `ґ` чи апостроф розміщено інакше).

## Автоматичні перевірки

`npm test` покриває всі десять пунктів розділу 8 технічного завдання:

| № | Вимога ТЗ | Де перевіряється |
|---|---|---|
| 1 | Формули SPM і точності на фіксованих прикладах | `tests/metrics.test.mjs` |
| 2 | Виправлена помилка входить до статистики | `tests/metrics.test.mjs` |
| 3 | Вправа етапу 2 не містить невідкритих символів | `tests/curriculum.test.mjs` (усі вправи, 8 варіантів кожної, обидві мови) |
| 4 | Кожна клавіша має рівно один палець | `tests/layouts.test.mjs` |
| 5 | `і ї є ґ` не підміняються | `tests/layouts.test.mjs`, `tests/metrics.test.mjs`, `tests/data.test.mjs` |
| 6 | Словники читаються у правильному кодуванні | `tests/data.test.mjs` |
| 7 | Контрольні суми сировини збігаються з маніфестом | `tests/data.test.mjs` |
| 8 | Повторна обробка дає той самий результат | `tests/data.test.mjs` |
| 9 | Прогрес зберігається після перезавантаження | `tests/storage.test.mjs`, `scripts/e2e.mjs` |
| 10 | Базове навчання працює офлайн | `tests/data.test.mjs` (повнота кешу service worker) |
| + | Кабінети, паролі, досвід, звання, досягнення | `tests/accounts.test.mjs` |
| + | Сервер кабінетів: вхід з іншого пристрою, секретне питання, захист від підбору, токени | `tests/server.test.mjs`, `tests/remote.test.mjs` |
| + | Зріз швидкості та сертифікати | `tests/certificate.test.mjs` |

`npm run test:e2e` запускає справжній браузер і проходить сценарій демонстрації: створення кабінету, вхід «з іншого комп'ютера», відновлення пароля, новий профіль, гама без підказки в заліку, навмисна помилка, слова з відкритих клавіш, вправа Академії, перезавантаження, сторінка джерел, вузький екран, відсутність помилок у консолі.

## Обмеження

- Потрібна фізична клавіатура. На вузькому екрані інтерфейс відображається коректно, але сенсорний екран навички не тренує.
- Тренажер не контролює, куди дивиться людина, і не стверджує, що може: камера не використовується. Підглядання стає зайвим завдяки поступовому відкриттю клавіш і заліку без екранної клавіатури.
- Секретне питання — слабший захист, ніж пошта: відповідь може вгадати знайома людина. Тому є пауза після п'яти невдалих спроб, а в кабінеті немає нічого, крім прогресу навчання.
- Якщо на двох пристроях одночасно набрано несинхронізований прогрес, зберігається серверна копія. Рейтингу між користувачами немає — лише особисті результати.
- Частотні списки походять із субтитрів, тому лексика розмовна. Частотність переходів між словами не обчислюється: для неї потрібен окремий ліцензований корпус.
- Клавішу <code>&#96;</code> закріплено за лівим мізинцем (класична схема), а не за правим, як у таблиці ТЗ 2.1: фізично вона розташована ліворуч від `1`. В українській розкладці це клавіша апострофа.
- Інтерфейс — українською для обох курсів.

## Використання AI

- **У готовому продукті AI немає.** Вправи, добір слів і рекомендації — детерміновані алгоритми, які працюють офлайн. Єдиний зовнішній запит застосунку — до власного сервера кабінетів.
- **Під час розробки** використано AI-асистента Claude Code (Anthropic). Він написав код застосунку, скрипти обробки словників, автоматичні тести, навчальні тексти Академії (`data/curriculum/content-*.json`) і документацію.
- **Перевірка результату:** 95 автоматичних тестів і наскрізний сценарій у браузері; перегляд згенерованого плану програми (`data/curriculum/outline-*.json`) і знімків екрана; вибірковий перегляд похідних списків слів із доповненням блок-листів.
- **Ручна перевірка учасником:** роботу тренажера перевірено вручну на фізичній клавіатурі — проходження вправ, реакцію на правильні й помилкові натискання клавіш, підрахунок результатів і збереження прогресу.
